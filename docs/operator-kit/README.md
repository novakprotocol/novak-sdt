# Operator Kit

The maintained N-SDT operator kit now lives in:

- `kits/operator-kit/`

It consolidates the useful material from the older `novakprotocol/novak-sdt-operator-kit` repo into the current N-SDT implementation.

## What it is

The operator kit is a lightweight starter for:

- zero-context handoff
- cold-start recovery
- next-operator continuity
- current-truth capture
- basic project-state capture

## What it is not

It is not RepoOps.

N-SDT operator kit establishes truth and continuity. RepoOps applies repo-operating standards, quality gates, profile alignment, and AI-agent governance after the truth floor is understood.

## Current status

The old operator-kit repo should be considered superseded after this consolidation lands. Archive or deletion of the old repo should happen only after owner review.
