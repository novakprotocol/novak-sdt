# SDT Birth Template Parity

## Decision

`sdt new` is the current N-SDT repo birth path.

The old `novak-repo-template` repo is treated as a legacy template source. Its
still-useful ideas are preserved here and in the current N-SDT generated floor.

## Current Birth Path

Use:

```text
sdt new --path <repo> --product-name <name> --product-statement <statement>
```

Then use:

```text
sdt doctor --path <repo>
```

## Parity Map

| Legacy template idea | Current N-SDT home |
|---|---|
| README and repo identity | `README.md` generated by `sdt new`. |
| Current truth | `WHAT_IS_REAL_NOW.md`. |
| Operator continuity | `PROJECT_STATE.md` and `docs/operator/`. |
| Product truth | `docs/product/`. |
| Public docs front door | `mkdocs.yml` and `docs/index.md`. |
| History/status lanes | `docs/history/`, `docs/status/`, `docs/estate/`. |
| Change intent | `docs/templates/SDT_CHANGE_INTENT_TEMPLATE.md` and `sdt change-bundle`. |
| Repo check | `sdt doctor`. |
| Report-only adoption | `sdt baseline --report-only`. |

## Template Rule Preserved

Do not keep files in a born repo just because the template had them.

Keep the truth and continuity floor. Remove or mark non-applicable lanes that do
not fit the real repo.

## What Changed

The old template was static.

N-SDT is now the active implementation because it can:

- create a new repo floor
- baseline an existing repo without overwriting by default
- show missing files in report-only mode
- check the floor with `sdt doctor`
- refresh or report truth surfaces

## Archive Decision

After this parity record exists, `novak-repo-template` can be renamed to:

```text
Archived20260701-novak-repo-template
```

and archived as historical template source.
