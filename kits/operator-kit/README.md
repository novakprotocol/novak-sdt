# N-SDT Operator Kit

This is the maintained N-SDT operator-kit starter.

It replaces the old `novakprotocol/novak-sdt-operator-kit` repository as the maintained home for the practical handoff/checklist material.

## Purpose

Use this kit when a repo needs a minimal truth and handoff floor before a new human or AI operator continues work.

The kit helps answer:

- What is real now?
- What changed?
- What is planned or assumed?
- What is risky?
- What should the next operator read first?
- What exact command or task should happen next?

## Boundary

N-SDT operator kit:

- product truth
- current state
- cold-start recovery
- handoff continuity
- next-operator packet
- rollback awareness

RepoOps:

- repo standards
- quality gates
- `AGENTS.md`
- command maps
- AI-agent governance
- checks and profile alignment

This kit is not RepoOps.

Use N-SDT first to establish truth and continuity. Use RepoOps second to apply repo-operating discipline.
