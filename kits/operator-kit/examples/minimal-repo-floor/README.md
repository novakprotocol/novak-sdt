# Minimal Repo Floor Example

This example shows the smallest useful N-SDT operator-kit floor for a repo that needs current truth and handoff continuity.

Files:

- `WHAT_IS_REAL_NOW.md`
- `PROJECT_STATE.md`
- `docs/operator/NEXT_OPERATOR_PACKET.md`

Use this as a starting point only. A real repo should fill these files with current, evidence-backed information.
